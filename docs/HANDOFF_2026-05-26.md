## Operational notes / pitfalls picked up today

- **Radix Dialog + Combobox:** modal Dialog sets
  `pointer-events: none` on the body. Anything portaled (like a
  base-ui Combobox popup) inherits that and silently eats mouse
  events. Either set `pointer-events-auto` on the popup root or
  use Radix Select instead — that's what HR + IT now do.
- **`FormControl` had a Slot bug.** Was rendering a plain `<div>`,
  so the generated `id` parked on the wrapper and the FormLabel's
  `htmlFor` pointed at a non-input. Switched to Radix `Slot`
  (#639). Cleared 55 DevTools warnings on the HR CRM dialog alone.
- **Per-workspace CRM perms were defined in code but never granted
  to any role.** All five `*-crm:manage` codes existed in
  `PERMISSION_DEFINITIONS` but no migration / seed inserted them
  into `role_permissions`. Admin worked because of the bypass in
  `resolvePermissions`; everyone else 403'd on ownership transfer.
  Fixed for HR Manager (#637) + Manager (#638). Any new per-team
  CRM permission code needs an accompanying grant migration.
- **codeload.github.com regional outage** — our runners hit 4xx
  for several hours on third-party action archives. We tried to
  swap them out for manual installs; codeload recovered before we
  needed to. If it happens again, see the diff in #641 + #642 for
  a working manual-WIF replacement.
- **GH Actions concurrency** can deadlock on a "queued / never
  scheduled" re-run. `cancel-in-progress: true` does not free
  that slot. GH API `cancel` returns 409 ("re-run that has not
  yet queued"). Only fix is to delete the run from the Actions
  UI (or `DELETE /actions/runs/<id>`).

## RBAC reminders (still current)

- `requireOwnerOrManage(role, perms, team)` permits the owner OR a
  holder of `projects:manage` OR the team-scoped `*-crm:manage`.
  Non-owners with only `*-crm:update` will still 403.
- HR Manager and Manager now hold the full workspace perms. Adding
  a sixth CRM team means: define the perms, grant them to the
  expected roles via migration, AND update
  `requireOwnerOrManage` to route the new team value.
